# 微光之渊

像素洞穴风格的 HTML 无限跑酷游戏。跳跃、攻击、切换重力，收集武器并积累火力，挑战精英与 Boss。

## 开始游戏

下载并用浏览器打开 **微光之渊.html**，无需安装依赖。**荧渊.html** 为相同内容的旧名入口。

开发入口为 `index.html`，配套源码需放在同一目录。

## 操作

| 动作 | 键鼠 | 手柄 |
| --- | --- | --- |
| 二段跳 | 空格 | A |
| 攻击 | 鼠标左键，按住连发 | X |
| 切换重力 | 鼠标右键 | RT |
| 冲刺 | Shift | LT |
| 弹反 | Q | LB |
| 俯冲 | S / ↓ | B |
| 大招 | F | Y |
| 暂停 | P / Esc | Start |

支持触屏按钮。近战通过武器道具获得。

## 开发

安装 Node.js 后运行：

```sh
npm test
npm run build
```

构建会将样式和脚本嵌入两个单文件 HTML。地图、道具与每局种子随机生成；游戏音乐和场景由代码绘制，无外部资源依赖。
