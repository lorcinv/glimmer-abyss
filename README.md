# 微光之渊

像素洞穴无限跑酷游戏。角色自动奔跑，你负责跳跃、攻击和切换重力。

## 开始游戏

下载 [微光之渊.html](./微光之渊.html)，用浏览器打开即可游玩。无需安装或联网。

## 玩法

- 每局随机组合地图、刷新道具，地面与顶壁都可通行。
- 拾取武器切换攻击方式，击杀和拾取武器提升本局火力，解锁多重弹、穿透与爆破。
- 积分越高，敌人越强；精英和 Boss 会持续追击，直到被击败。

## 操作

| 动作 | 键鼠 | 手柄 |
| --- | --- | --- |
| 二段跳 | 空格 | A |
| 攻击（按住连发） | 鼠标左键 | X |
| 切换重力 | 鼠标右键 | RT |
| 冲刺 | Shift | LT |
| 弹反 | Q | LB |
| 俯冲 | S / ↓ | B |
| 大招（蓄满后释放） | F | Y |
| 暂停 | P / Esc | Start |

手机使用画面下方的触屏按钮。近战攻击需拾取辉刃或裂枪。

## 开发

源码入口为 `index.html`，需与样式、脚本放在同一目录。安装 Node.js 后运行：

```sh
npm test       # 检查玩法
npm run build  # 生成单文件游戏
```

构建只生成 `微光之渊.html`。场景与音乐由代码生成，无外部资源依赖。
